# Validation Ladder

## V0 — Specification Validity

Freeze terminology, assumptions, units, interfaces, models and acceptance criteria.

## V1 — Component Correctness

Validate individual components against analytical results, trusted references
or independent golden implementations.

## V2 — Cross-Implementation Correctness

Compare independent implementations or computational backends where possible.

## V3 — Integrated Functional Correctness

Execute representative workloads through the complete integrated pipeline.

## V4 — Stress and Failure Validation

Test limits, saturation, malformed input, backpressure, invalid states and
other relevant failure conditions.

## V5 — Controlled Performance Evaluation

Freeze benchmark configurations and establish repeatable instrumentation.

## V6 — Research Experiment

Execute the controlled experiment matrix required to answer the main research
question.

## V7 — Clean Reproduction

Regenerate the principal metrics, figures and tables from a clean repository
checkout and documented environment.
