# Contributing

Contributions, technical discussion, validation checks and reproducibility
improvements are welcome.

## Research standards

Contributions should preserve:

- scientific and mathematical correctness;
- reproducibility;
- explicit assumptions and interfaces;
- validation against trusted references or baselines;
- separation of measured, simulated and modelled results;
- traceable experimental configurations;
- clear documentation of limitations.

## Development workflow

1. Create a dedicated branch.
2. Implement the proposed change.
3. Add or update appropriate tests.
4. Run relevant validation and regression checks.
5. Document consequential methodological or architectural decisions.
6. Submit a pull request describing the motivation, implementation and evidence.

Performance improvements must not compromise correctness or reproducibility.

For substantial scientific or architectural changes, open an issue before
implementation so that the proposed direction can be discussed.
